- المالك يحدد:
  1. حد الطلبات النشطة، وهل يختلف حسب الفئة أو المنطقة.
  2. حد الصور، وهل يُسمح بفيديو (غير مدعوم حالياً).
  3. **هل تُفعَّل المراجعة قبل النشر افتراضياً؟** ومن يراجعها (دور)؟ وما مهلة المراجعة؟
  4. مدة انتهاء العنصر، وهل تُجدَّد تلقائياً أم بطلب المتبرع.
  5. معدلات الإنشاء/الطلبات/الدردشة، وهل تختلف للأدوار.
  6. **توجيه طلب الاستفادة: المتبرع أم الفريق؟** (HRD §4 يطلب «حسب الإعداد» — **غير منفَّذ**، `PROJECT_CONTEXT #85`).
  7. **مدة احتفاظ دردشة التنسيق** (غير منفَّذة — مرتبطة بـ#7).
  8. هل التقييم يبقى خاص بالفريق دائماً (الحالي) أم يُعرض مُجمَّعاً بلا هويات؟
- **قيود حاكمة:**
  - **لا سعر ولا مقابل مالي في أي كيان** (ADR-0063) — التقدير للإحصاء فقط وموسوم «غير موثقة».
  - **شرط عدم إعادة البيع إلزامي** عند الإضافة.
  - **كشف الاتصال لا يتم قبل القبول وبموافقة الطرفين** (ADR-0064).
  - **رمز التسليم يُعرض لطرف واحد** وإلا فقد التأكيد المزدوج معناه (ADR-0065).
  - **التقييم ليس تصنيفاً أخلاقياً** ولا يؤثر على أهلية أحد (ADR-0066).
