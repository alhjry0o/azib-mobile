# المسرد (GLOSSARY)

مصطلحات المشروع بالعربية والإنجليزية لتوحيد اللغة في الكود والوثائق والواجهة. الترجمة في الواجهة تتم عبر i18n فقط. هذه الوثيقة مرجع للمصطلحات لا مصدر نصوص للتطبيق.

## المنتج والمجال

مصطلحات تخص مجال الزواج والمساعدات والشركاء:

| المصطلح العربي | English | التعريف |
|---|---|---|
| عازب | AZIB | اسم المنصة، منصة اجتماعية غير ربحية لتيسير الزواج |
| غير ربحي | Non-profit | بلا عمولات ولا اشتراكات ولا أرباح موزعة |
| مساعدة مالية منضبطة | Controlled financial assistance | مساعدة تُمنح بعد تحقق ومراجعة بشرية وفق سياسات معتمدة |
| طلب مساعدة | Assistance request | طلب يقدمه مستخدم للحصول على مساعدة |
| الاستحقاق | Eligibility | استيفاء شروط تحددها السياسات (POL-01) |
| التحقق | Verification | التأكد من صحة المعلومات والوثائق قبل أي مساعدة |
| عرس جماعي | Group wedding | حفل زواج مشترك لعدة أسر بتكلفة مشتركة |
| شريك | Partner | جهة تقدم خصومات أو خدمات للمستفيدين |
| سفير | Ambassador | شخص يمثل المنصة ويدعم نشرها |
| سوق خير | Souk Khair | سوق للتبرعات العينية |
| تبرع عيني | In-kind donation | تبرع بسلع أو أغراض لا بمال |
| متطوع | Volunteer | شخص يقدم وقته أو مهارته دون مقابل |
| مستفيد | Beneficiary | من يحصل على مساعدة؛ بياناته محمية (R-20) |
| متبرع | Donor | من يتبرع للمنصة أو مستفيد |
| اختيار الزوج مسؤولية الأسر | Spouse selection is the families' responsibility | مبدأ: لا تعارف ولا ملفات عامة للأفراد |
| القمريات | Qamariya | النوافذ الزجاجية الملونة التقليدية في العمارة اليمنية، وهي فكرة الهوية البصرية |
| ريال يمني | YER | العملة المعتمدة في السوق الأول |

## الأدوار

أسماء الأدوار كما تُستخدم في الكود (الوصف أولي، والصلاحيات تفصل في P03):

| المصطلح العربي | الدور (Role) | التعريف |
|---|---|---|
| زائر | `guest` | غير مسجل |
| عضو | `member` | مستخدم مسجل |
| مقدّم طلب | `applicant` | عضو قدّم طلباً |
| متبرع | `donor` | متبرع |
| صاحب شريك | `partner_owner` | يدير جهة شريكة |
| سفير | `ambassador` | سفير المنصة |
| متطوع | `volunteer` | متطوع |
| مراجع | `reviewer` | يراجع الطلبات ويتخذ قراراً بشرياً |
| مشرف | `moderator` | يشرف على المحتوى والمجتمع |
| مدقق شركاء | `partner_verifier` | يتحقق من الشركاء |
| مسؤول مالي | `finance_officer` | يتولى الجوانب المالية الإدارية |
| محرر محتوى | `content_editor` | يحرر المحتوى التوعوي |
| مسؤول النظام | `admin` | إدارة النظام |
| مدقق | `auditor` | اطلاع وتدقيق |

## الهندسة والأدوات

مصطلحات تقنية مستخدمة في المشروع:

| المصطلح العربي | English | التعريف |
|---|---|---|
| طبقة تجريد المزوّد | Provider Abstraction | واجهة تخفي مزود الخدمة (مثل Supabase) لإمكان الاستبدال والاختبار |
| غير متصل | Not Connected | شاشة وحالة تعرض بصدق أن الخدمة غير متصلة، دون ادعاء نجاح |
| بيانات تجريبية | Demo data | بيانات اصطناعية تحمل `dataOrigin='demo'` |
| مصدر البيانات | `dataOrigin` | حقل يميز البيانات التجريبية عن الحقيقية |
| بيانات أولية | Seed | بيانات تُحمَّل لتهيئة النظام (اصطناعية فقط) |
| حالة الخادم | Server state | بيانات بعيدة تُدار بـTanStack Query |
| حالة العميل | Client state | حالة الواجهة المحلية وتُدار بـZustand |
| سجل القرار المعماري | ADR | سجل مختصر لقرار معماري |
| قاعدة صارمة | HRD | قواعد الحوكمة الصارمة التسع |
| أمان على مستوى الصف | RLS | Row Level Security: ضبط الوصول للصفوف في قاعدة البيانات |
| اختبار قاعدة البيانات | pgTAP | إطار اختبار لـPostgreSQL |
| اختبار شامل | E2E | End-to-End: اختبار التدفق كاملاً |
| تكامل مستمر | CI | تشغيل الفحوص آلياً (GitHub Actions) |

## الأمان والخصوصية

مصطلحات الأمان والمالية:

| المصطلح العربي | English | التعريف |
|---|---|---|
| غير حافظ | Non-Custodial | التطبيق لا يحتفظ بأموال المستخدمين (ADR-0005) |
| ضمان وسيط | Escrow | احتفاظ طرف ثالث بالمال حتى استيفاء شرط؛ غير مدعوم |
| استشاري | Advisory | تقييم آلي يرشد المراجع ولا يقرر (ADR-0006) |
| مراجعة بشرية | Human review | قرار إنسان مسؤول هو النهائي |
| نموذج التهديدات | Threat model | تحليل للتهديدات والضوابط (STRIDE) |
| ستْرايد | STRIDE | تصنيف تهديدات: انتحال، عبث، إنكار، كشف معلومات، حجب خدمة، رفع صلاحيات |
| أقل صلاحية | Least privilege | منح أقل صلاحيات لازمة |
| تقليل البيانات | Data minimization | جمع الحد الأدنى من البيانات |
| سجل تدقيق | Audit log | سجل غير قابل للتعديل للإجراءات الحساسة |
| إعادة تعريف الهوية | Re-identification | استنتاج هوية شخص من بيانات مجمّعة |
| حد إخفاء الإحصاءات | Small-cell suppression threshold | العتبة الدنيا لعرض إحصاءات (POL-08) |
| سر | Secret | مفتاح أو كلمة مرور لا يجوز نشرها (R-06) |
