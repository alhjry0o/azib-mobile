# GLOSSARY — مصطلحات المشروع (عربي / English)

> مصطلحات موحّدة تُستخدم في الوثائق، الكود، ورسائل i18n.
> **عام المستودع:** لا أسرار ولا بيانات حقيقية.

---

## 1) الهوية والمشروع

| العربية | English | تعريف مختصر |
|---------|---------|-------------|
| عازب / عزباء | Azib / Single | من لم يسبق له الزواج، وهو المستخدم الأساسي المستهدف. |
| AZIB | AZIB | الاسم التجاري/العلامة للمنصة. |
| القمرية | Qamariya | عنصر معماري يمني (نافذة دائرية مزخرفة)، يُستخدم كموتيف بصري. |
| الحلقتان المتداخلتان | Interlocking Rings | رمز بصري للزواج في هوية المنصة. |

---

## 2) الأدوار (Roles)

| العربية | English | تعريف |
|---------|---------|-------|
| زائر | guest | مستخدم غير مسجَّل. |
| عضو | member | مستخدم مسجَّل. |
| متقدم | applicant | عضو تقدم بطلب مساعدة/تسجيل زواج. |
| متبرع | donor | عضو سجّل تبرعاً (عيني أو مالي عبر مزوّد). |
| شريك | partner | جهة تجارية مقدّمة خصومات. |
| مالك شريك | partner_owner | المسؤول عن حساب الشريك. |
| سفير | ambassador | عضو يسوّق للمنصة ويربط شركاء. |
| متطوع | volunteer | عضو يقدم وقتاً/مهارة. |
| مراجع | reviewer | مسؤول مراجعة أهلية المتقدمين. |
| مشرف | moderator | مسؤول محتوى/إشراف. |
| مدقق شركاء | partner_verifier | يتحقق من صحة الشريك ومستنداته. |
| مسؤول مالي | finance_officer | مسؤول تسجيل التبرعات وسجلاتها. |
| محرر محتوى | content_editor | مسؤول التوعية والمقالات والميثاق. |
| مدير | admin | أعلى صلاحية تشغيلية. |
| مدقق | auditor | صلاحية قراءة/تدقيق بلا تعديل. |

---

## 3) المجالات الوظيفية

| العربية | English | تعريف |
|---------|---------|-------|
| مساعدة | Assistance | مساعدة مالية منضبطة للمستفيد. |
| أهلية | Eligibility | مدى استحقاق المتقدم، تقريرها مراجعة بشرية + تقييم استشاري. |
| تقييم استشاري | Advisory Score | درجة آلية مساعدة، لا تُنتج قراراً نهائياً. |
| عرس جماعي | Group Wedding | تنظيم زواج جماعي بتكاليف مشتركة. |
| سوق خير | Souk / Charity Market | تبرعات عينية (أثاث، أجهزة، ملابس...). |
| وظائف | Jobs | فرص عمل مقدّمة من شركاء/مجتمع. |
| متطوعون | Volunteers | تسجيل ومهام تطوعية. |
| توعية | Education | محتوى توعوي للشباب والأسر. |
| الميثاق | Charter | مبادئ وسلوك المجتمع. |
| الأثر | Impact | مؤشرات أثر المنصة. |
| حاسبة الزواج | Wedding Calculator | أداة إرشادية لتقدير التكلفة (Advisory). |

## 4) مفاهيم مالية

| العربية | English | تعريف |
|---------|---------|-------|
| غير حافظ للأموال | Non-Custodial | المنصة لا تحتفظ بأموال المستخدمين. |
| الضمان | Escrow | **غير مستخدم** — ممنوع. |
| سجل مساعدة | Assistance Record | سجل داخلي بقرار/صرف مساعدة (ليس حساب أموال). |
| ريال يمني | YER | عملة السوق الأول. |
| المزوّد المرخّص | Licensed Provider | مزوّد دفع خارجي مرخّص تُسجَّل عبره التبرعات الحقيقية. |

## 5) التقنية

| العربية | English | تعريف |
|---------|---------|-------|
| الوكيل | Agent | منفّذ المراحل (بشري/آلي) ويلتزم بـ AGENT_RULES. |
| الحوكمة | Governance | ملفات AGENT_RULES/DECISIONS/POLICIES. |
| عقد المزوّد | Provider Abstraction | واجهة موحدة تُخفي تفاصيل Supabase عن بقية الكود. |
| بيانات البذر | Seed Data | بيانات تجريبية تحمل `dataOrigin='demo'`. |
| أصل البيانات | Data Origin | حقل صريح يميّز `demo` عن `real` في أي كيان. |
| حالة الخادم | Server State | بيانات تُدار بـ TanStack Query. |
| حالة العميل | Client State | حالة واجهة تُدار بـ Zustand. |
| RTL | Right-to-Left | اتجاه الواجهة العربية، يُنفّذ بـ Logical Properties. |
| i18n | Internationalization | كل النصوص من ملفات الترجمة فقط. |
| Not Connected | Not Connected | شاشة/حالة صادقة تعني «غير متصل»، لا تُخفي أنها كذلك. |
```
