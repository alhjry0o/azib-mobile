# ASSET_LICENSES — سجل تراخيص الأصول البصرية والصوتية

> **عام المستودع:** لا أسرار ولا بيانات شخصية.
> أي أصل بصري أو صوتي أو خط أو أيقونة يُضاف للمشروع يجب أن يُسجَّل هنا **قبل** الاستخدام.
> لا يُستخدم أصل مجهول المصدر مطلقاً.

---

## 1) القواعد

1. كل أصل له مصدر مرخّص واضح (رخصة تجارية، CC، ملكية داخلية، مجانية بشرط الإشارة).
2. لا صور لوجوه حقيقية يمكن التعرّف عليها لغير المستخدمين (خصوصية المستفيدين).
3. لا صور لأطفال يمكن التعرّف عليهم.
4. لا صور لأفراد بأسماء وهمية توحي بأنها حقيقية دون وسم Demo.
5. الأصول التوليدية (AI) تُسجَّل أيضاً مع الأداة والسياسة.
6. الأصل الذي رخصته لا يسمح بإعادة التوزيع = لا يُدرج في المستودع العام.
