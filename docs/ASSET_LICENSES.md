# تراخيص الأصول (ASSET_LICENSES)

هيكل لتتبع مصدر وترخيص كل أصل غير برمجي (خطوط، أيقونات، صور، صوت، نماذج 3D، رسوم) وأي أصل تُلزم رخصته بإسناد أو قيود. **لا يُضاف أصل إلى المستودع دون إدخاله هنا.** هذا المستودع عام، فالمعلومات هنا عامة.

## الحالة الحالية

في P01 لا توجد أصول مضافة. الجدول فارغ عمداً، ويُملأ ابتداءً من P04 (Design System).

## قواعد عامة

شروط قبول أي أصل:

1. **المصدر والترخيص معروفان وموثقان** برابط. أي أصل بلا ترخيص واضح يُرفض.
2. **السماح بالاستخدام** في تطبيق غير ربحي وبإعادة التوزيع ضمن التطبيق، وبالتعديل إن لزم.
3. **الإسناد (Attribution):** إن كان مطلوباً يُدرج في شاشة الإسناد وفي هذا السجل.
4. **الخطوط:** يجب دعمها للعربية (التشكيل والربط)، وأن يسمح ترخيصها بالتضمين في تطبيقات.
5. **أصول مولدة بالذكاء الاصطناعي:** تُعلَن صراحة بأداة التوليد وشروط الأداة.
6. **أصول الهوية** (الشعار، القمريات، الحلقتان): تأكيد ملكية المشروع لها قرار بشري.
7. **لا أصول حقيقية للأشخاص:** لا صور أو أصوات لأشخاص حقيقيين دون موافقة موثقة، ولا صور مستفيدين.

## سياسة التراخيص (مقترحة، بانتظار قرار بشري/قانوني)

تصنيف مقترح يحتاج اعتماد المالك:

| التصنيف | أمثلة | الإجراء |
|---|---|---|
| مسموح | MIT، Apache-2.0، OFL-1.1 (للخطوط)، CC0، BSD | يُسجَّل |
| مسموح بشرط | CC-BY (إسناد مطلوب) | يُسجَّل مع نص الإسناد |
| يحتاج مراجعة | CC-BY-SA، GPL/AGPL/LGPL | مراجعة قانونية قبل الاستخدام |
| مرفوض | بلا ترخيص، CC-NC، «مجاني للاستخدام الشخصي»، ترخيص غير واضح | لا يُضاف |

## تراخيص الحزم البرمجية

حزم npm لها تراخيصها أيضاً. أداة الفحص الآلي للتراخيص لم تُختر بعد، وتُقرَّر وتُتحقق في P21/P22 قبل اعتمادها (R-08). حتى ذلك الحين تُراجَع رخصة كل حزمة يدوياً عند إضافتها وتُسجَّل في PROJECT_CONTEXT.md.

## قائمة تحقق عند إضافة أصل

قبل الدمج:

1. هل المصدر والمؤلف موثقان؟
2. هل الترخيص يسمح بالاستخدام والتوزيع المطلوب؟
3. هل أُدخل الأصل في السجل أعلاه؟
4. هل الإسناد (إن لزم) مضاف للتطبيق؟
5. هل الخط يدعم العربية وتم اختباره في RTL؟
6. هل الحجم مقبول للأداء (P20)؟

## ترخيص المستودع نفسه

ترخيص كود المستودع ووثائقه **غير محدد** (قرار بشري معلّق). لا يُفترض ترخيص حتى يُضاف ملف ترخيص رسمي.
