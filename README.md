# عازب | AZIB

منصة اجتماعية غير ربحية لتيسير الزواج في اليمن، تبدأ من صنعاء. تجمع في تطبيق واحد: مساعدات مالية منضبطة بعد التحقق، وأعراساً جماعية، وشركاء بخصومات، وسوق خير للتبرعات العينية، ووظائف، ومتطوعين، ومحتوى توعوي.

> **حالة المستودع: المرحلة P01 (حوكمة ووثائق فقط).**
> لا يوجد كود تطبيق بعد. التطبيق لم يُهيَّأ (يبدأ ذلك في P02). لا تعتمد على هذا المستودع كمنتج قابل للتشغيل.

## ما هو المشروع

- **غير ربحي:** بلا عمولات ولا اشتراكات.
- **ليس تطبيق تعارف:** لا خدمات تعارف ولا ملفات عامة للأفراد. اختيار الزوج مسؤولية الأسر.
- **لا مساعدة دون تحقق:** القرار النهائي دائماً لمراجعة بشرية، والتقييم الآلي استشاري (Advisory) فقط.
- **Non-Custodial:** التطبيق لا يحتفظ بأموال، ولا يملك محفظة، ولا يقدّم خدمة ضمان (Escrow).
- **الخصوصية والشفافية:** بيانات المستفيدين لا تُكشف لغير المخوّلين.

## السوق واللغة

- السوق الأول: صنعاء / اليمن. العملة: YER.
- اللغة الافتراضية: العربية (`ar`) مع RTL. البنية متعددة اللغات من اليوم الأول.

## المكدس التقني المعتمد (مخطط، غير منفّذ بعد)

Expo + React Native + TypeScript (Strict) + Expo Router، Zustand وTanStack Query، React Hook Form وZod، i18next، Reanimated وGesture Handler، Supabase خلف طبقة Provider Abstraction، Jest وRNTL وPlaywright (Web) وpgTAP، GitHub Actions، ومدير الحزم npm.

لا تُعدّ إصدارات الأدوات مثبّتة حتى تُسجَّل في `PROJECT_CONTEXT.md` ضمن P02.
