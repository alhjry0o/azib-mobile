# عازب | AZIB

منصة اجتماعية **غير ربحية** لتيسير الزواج في السوق الأول (صنعاء/اليمن).

تهدف المنصة إلى تخفيف تكاليف الزواج وتيسير السبل له عبر:
- مساعدات مالية منضبطة بمراجعة أهلية بشرية.
- أعراس جماعية.
- شركاء بخصومات.
- سوق خير للتبرعات العينية.
- وظائف ومتطوعون.
- محتوى توعوي وميثاق مجتمعي.

## قيود صادقة معروفة

- **القيم مؤقتة:** عتبة الأصول والنطاقات والنافذة وحدود المستند موسومة `PENDING_POLICY` وتنتظر اعتماد المالك. **الأوزان وحدها محسومة من HRD.**
- **لا قرار آلي:** فشل البوابة يُحيل لمراجع بشري؛ المحاكي في `(dev)` فقط.
- **بصمة المستند وصفية:** إعادة تسمية الملف تُفلت من كشف التكرار؛ بصمة المحتوى + HMAC في P18.
- **PDF بلا معالجة:** لا ندّعي إزالة بياناته الوصفية.
- **الإحصاءات محجوبة** لأن حجم البيانات التجريبي دون الحد؛ والمبلغ يُحجب مع العدد.
- **قصص النجاح فارغة** حتى تُضاف موافقة لكل سجل محتوى (P15).
- **الحذف مجدول لا منفَّذ**؛ صورة المستخدم تُحفظ في الجلسة فقط حتى P18.
- شاشات الميزات غير المنفذة تعرض **Placeholder صادقاً** يذكر مرحلتها (P10–P17). لا أزرار شكلية.

## المبادئ الحاكمة

- غير ربحي: لا عمولات، لا اشتراكات، لا رسوم على المستفيدين.
- لا خدمات تعارف، ولا ملفات عامة للأفراد.
- اختيار الزوج مسؤولية الأسر.
- لا مساعدة دون تحقق بشري.
- Non-Custodial: لا محفظة، لا Escrow، لا تحويل داخلي.
- تقييم آلي **Advisory** فقط.
- ثروة الأقارب والميراث غير المستلم **لا تُسقط الاستحقاق**.
