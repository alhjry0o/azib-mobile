# عازب | AZIB

منصة اجتماعية **غير ربحية** لتيسير الزواج في السوق الأول (صنعاء/اليمن).

تهدف المنصة إلى تخفيف تكاليف الزواج وتيسير السبل له عبر:
- مساعدات مالية منضبطة بمراجعة أهلية بشرية.
- أعراس جماعية.
- شركاء بخصومات.
- سوق خير للتبرعات العينية.
- وظائف ومتطوعون.
- محتوى توعوي وميثاق مجتمعي.

## قيود صادقة معروفة

- **لا تبرع حقيقي ولا إيصال رسمي** قبل ربط جهة مرخّصة + Webhook خادمي بتوقيع (P18). شاشة المتطلبات تسرد ما ينقص.
- **`verified` لا يكتبه العميل** — يحتاج فاعلاً مالياً وتأكيد المزوّد فعلاً.
- **تقرير الأثر فارغ في الوضع التجريبي** لأن كل البيانات demo — سلوك مقصود لا عطل.
- **إحصاءات الرئيسية** ما زالت تقرأ حالة قديمة ⇒ تحتاج توحيداً مع `verified` (P15/P18).
- **الصرف عبر محاكي** في `(dev)`؛ لوحة Maker/Checker بصلاحيات حقيقية في P17.
- **القرض الحسن معلومات وإحالة فقط** — لا إقراض ولا تحصيل داخل التطبيق، ولا جهة إحالة مربوطة بعد.
- **القيم المؤقتة** (عتبة الأصول، النطاقات، النافذة، حد الإخفاء) موسومة وتنتظر اعتماد المالك. **الأوزان وحدها محسومة.**
- **الحذف مجدول لا منفَّذ**؛ صورة المستخدم وإيصال التبرع غير دائمين حتى P18.
- شاشات الميزات غير المنفذة تعرض **Placeholder صادقاً** يذكر مرحلتها (P10–P17). لا أزرار شكلية.

## المبادئ الحاكمة

- غير ربحي: لا عمولات، لا اشتراكات، لا رسوم على المستفيدين.
- لا خدمات تعارف، ولا ملفات عامة للأفراد.
- اختيار الزوج مسؤولية الأسر.
- لا مساعدة دون تحقق بشري.
- Non-Custodial: لا محفظة، لا Escrow، لا تحويل داخلي، لا أرصدة.
- تقييم آلي **Advisory** فقط.
- ثروة الأقارب والميراث غير المستلم **لا تُسقط الاستحقاق**.
- **نية تبرع ≠ مبلغ مستلم** — ولا إيصال قبل تحقق مالي.
